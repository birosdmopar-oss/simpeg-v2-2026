## Metode

1. **`./check.sh` penuh** pada hasil gabungan di worktree integrasi (DB test unik).
2. **Tiga area QA API paralel**, masing-masing dengan DB scratch dan port sendiri; akun dari seeder test, password seed lokal (lihat README seed). Override konfigurasi per instance lewat `auto_prepend_file` karena PHP Windows (`variables_order=GPCS`) tidak meneruskan env var bertitik ke `$_ENV`.
3. **Race**: HTTP 8 instance `spark serve` serentak (`curl_multi`) dan CLI barrier (proses `php` ter-bootstrap CI4), dengan skew mulai ≤17 ms.
4. **UI**: halaman login, lupa password, dan reset password di browser (desktop dan 375 px). Langkah yang butuh mengetik password (ganti password, simpan password baru) diuji lewat test komponen (Vitest) dan QA API, tidak lewat browser.
