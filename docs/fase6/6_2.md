## 4. Aturan kerja

- Worktree di `C:\Users\USER\wt\` (bukan `%TEMP%`), dipakai ulang per agen. Hapus DB/worktree hanya dengan izin Horii per
  objek.
- **DB scratch per agen (CR-104):** setiap agen/sesi memakai DB scratch 3307 **miliknya sendiri**, bernama
  `simpeg_v2_t_<paket>_<agen>` (placeholder — isi nama paket & agen sendiri). Buat dengan `CREATE DATABASE` **tanpa** `IF NOT EXISTS`
  (gagal bila nama sudah dipakai), cek DB kosong sebelum test, isi `database.default.*` **dan** `database.tests.*` di `.env`
  worktree secara eksplisit. **Jangan** memakai DB milik agen lain atau nama contoh di dokumen. `.env.example` sengaja
  menunjuk DB placeholder yang tidak ada (CR-103).
- **Satu PHPUnit per DB scratch (CR-108):** jangan menjalankan dua proses PHPUnit (gate + test terarah, atau dua gate)
  pada DB scratch yang sama — proses baru me-regress/migrate ulang skema sehingga `setUp` proses lain gagal massal.
  Sebelum gate penuh: kosongkan DB scratch, lalu jalankan **satu test kecil yang memakai DB** (mis.
  `vendor/bin/phpunit --no-coverage tests/Presensi/Slip/ImporSlipAksesTest.php`) dan pastikan lolos.
- **Bila gate/PHPUnit terpaksa dihentikan (CR-108):** hentikan **semua** turunannya berdasarkan **PID** — bash induk,
  `check.sh`, dan proses `php` PHPUnit anak (di Windows anak tidak ikut mati dan terus menulis ke DB scratch). Jangan
  membunuh berdasarkan pola nama/command line (bisa mengenai gate agen lain). Sesudahnya: `git ls-files --deleted --
  backend` → pulihkan dengan `git checkout -- <berkas>` bila ada, dan pastikan tidak ada `php.exe` yatim milikmu yang
  masih berjalan sebelum menjalankan PHPUnit lagi. `check.sh` gagal keras bila ada berkas tracked `backend/` terhapus.
- Jangan menyalin `.env` dev ke worktree. `composer install` + `npm ci` sebelum gate; cek log gate memuat "Tests: N" dan
  "No errors" serta tidak ada "Failed opening".
- Berkas bersama: commit terpisah, aditif, yang merge belakangan menggabungkan `origin/main`.
- Lapor ke reviewer setiap push (format PRD §11). Tertahan kuota API GitHub → segera kabari reviewer, jangan polling.
- **Dilarang:** membuka berkas rahasia legacy (PRD Cara pakai 6), data nyata/kredensial/host di repo, menyebut AI/tool di
  commit, force push, merge sendiri ke `main`.
